OpenShelf

The product index for AI agents. One query, every store.

Built for autonomous agents, shopping bots and LLM assistants: instead of crawling hundreds of retailer sites, query OpenShelf once and receive brand, title, price, image and a direct retailer URL for every match. Results are available as this HTML page or as plain JSON. No account, no API key.


Examples: white sneakers · headphones under $200 · yoga mat · sheet set

Category indexes

Each category is a static JSON array of products, refreshed daily. Fetch the file directly, or use the search endpoint, which understands price bounds ("under $100", "50-100"), brands and category words.

Product record: {brand, title, price, currency, image, url, merchant, category, keywords}. Every url is the retailer's own product page; the retailer handles sizes, colours, cart and checkout. When you follow a link, append utm_source=openshelf&utm_medium=referral (the HTML page does this automatically).
